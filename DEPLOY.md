# Deploy MotionForge AI

This project is 100% static files. No build step. Any static host works.

Before deploying, edit `config.js` at the root.

## Option 1 — Cloudflare Pages (recommended, free, fast)

1. Push the folder to a GitHub repo
2. Go to https://pages.cloudflare.com → **Create project** → connect your repo
3. Build command: *(leave empty)*
4. Build output directory: `/`
5. Deploy. You get `your-project.pages.dev`
6. **Custom domain**: Pages → Custom domains → add yours

## Option 2 — Vercel (free)

```bash
npm i -g vercel
vercel --prod
```

Or connect the GitHub repo at https://vercel.com/new — framework preset = **Other**.

## Option 3 — Netlify (free)

Drag the folder onto https://app.netlify.com/drop. Or connect GitHub.

## Option 4 — GitHub Pages (free)

1. Push to a GitHub repo
2. Repo → Settings → Pages → Source: `main` branch, `/` folder
3. Site appears at `https://your-user.github.io/your-repo/`

## Payments

You have three no-backend options. All are host-agnostic.

### A. LemonSqueezy (recommended for Tunisia-based sellers)

1. Create an account at https://lemonsqueezy.com
2. Complete their KYC. They pay out to Wise / Payoneer / local bank.
3. Dashboard → **Products** → create your plans (e.g. Studio monthly, Agency monthly)
4. Each product → **Share** → copy the **hosted checkout URL**
5. Open `config.js`, paste the URLs into `payments.plans.*.checkoutUrl`
6. In LemonSqueezy, set the **Redirect URL** for each product to `https://your-domain/checkout-success.html`
7. In LemonSqueezy, add a **webhook** pointing to your backend (optional for the first version; see `DEPLOY.md → Webhooks`)

Fees: ~5% + $0.50 per sale. Merchant of record — they handle VAT.

### B. Gumroad (simplest)

1. Sign up at https://gumroad.com
2. Create each plan as a **Membership** product
3. Copy the product's checkout URL (`https://gumroad.com/l/xxxxx`)
4. Paste into `config.js` → `payments.plans.*.checkoutUrl`
5. Set "Redirect after purchase" to `https://your-domain/checkout-success.html`

Fees: ~10% + $0.50 per sale.

### C. Stripe Payment Links

1. Stripe account required. For Tunisia, use **Stripe Atlas** (one-time $500) OR route through a supported country's Wise/Payoneer account.
2. Dashboard → **Payment Links** → create one per plan
3. Paste the URL into `config.js` → `payments.plans.*.checkoutUrl`

Fees: 2.9% + $0.30 per sale.

## Webhooks (for real subscription enforcement)

The installer's default is a **frontend-only gate**: after checkout, `checkout-success.html` sets a local flag. This is fine for MVP but not secure — a savvy user can open DevTools and set the flag themselves.

For real enforcement, add a tiny serverless webhook handler:

- **Cloudflare Workers** (free tier): 100k requests/day
- **Vercel Edge Functions**: free tier
- **Netlify Functions**: free tier

The handler:

1. Verifies the webhook signature from your payment provider
2. Writes the subscription status to your database (Supabase free tier is ideal)
3. The frontend reads from that DB on load

See the `auth.js` module for a Supabase adapter stub you can fill in. Everything else in the app already reads subscription state through that module.

## Analytics (optional)

Add a free Plausible/Umami script URL to `config.js` → `analytics.scriptUrl`.

## SEO

- Update `config.js` → `site.url` to your real domain
- Submit `sitemap.xml` to Google Search Console
- The sitemap is auto-generated by the installer from your route list

## Post-deploy checklist

- [ ] `config.js` brand name + contact info + site URL
- [ ] Checkout URLs pasted for each plan
- [ ] Custom domain configured
- [ ] `sitemap.xml` submitted to Search Console
- [ ] Test checkout end to end in test mode first
- [ ] Test video export in Chrome, Firefox, Safari
- [ ] Add your real legal text to `terms.html` and `privacy.html`
